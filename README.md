# Todo List App 📝

A simple and interactive **Todo List web application** built using **HTML, Tailwind CSS, and JavaScript**. Users can add, edit, delete, and mark tasks as completed. The application also displays the total number of tasks and completed tasks dynamically.

### ✨ Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 📊 Dynamic task and completion counters
* ❌ Cancel edit mode
* 🎨 Clean and responsive UI
* ⚡ Built with vanilla JavaScript and Tailwind CSS

### 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* JavaScript (DOM Manipulation & Event Delegation)
